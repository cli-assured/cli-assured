= Install and invoke Maven

[.since]#0.0.1#

The utility methods for installing and invoking Maven are available in `cli-assured-maven` artifact:

[source,xml]
----
<dependency>
  <groupId>org.cli-assured</groupId>
  <artifactId>cli-assured-maven</artifactId>
  <version><!-- Use the latest --></version>
</dependency>
----

Find the latest version on https://central.sonatype.com/artifact/org.cli-assured/cli-assured-maven[Maven Central].

There are two ways how to specify the Maven version to install and run:

* By version literal
* By querying `.mvn/wrapper/maven-wrapper.properties`

[[configure-maven-download-repository]]
== Use a custom Maven download repository

[.since]#0.2.2#

When installing Maven with `Maven.version(String)` or `Maven.fromMvnw()`, CLI Assured computes the default distribution URL
using the first available repository URL from the following list:

. The `mvnw.repo.url` system property.
. The `MVNW_REPOURL` environment variable.
. `https://repo.maven.apache.org/maven2` (Maven Central).

Set the system property in the configuration of Surefire or Failsafe Maven plugins, or set `MVNW_REPOURL` in the environment
before starting the Java process:

[source,shell]
----
export MVNW_REPOURL=https://repo.example.org/maven2
----

CLI Assured constructs the download URL using this template:

[source,text]
----
<repository-url>/org/apache/maven/apache-maven/<version>/apache-maven-<version>-bin.zip
----

The repository must also provide the corresponding `.zip.sha512` file, which CLI Assured uses to verify the download.

An explicit `MavenSpec.distributionUrl(String)` still takes precedence over these repository settings.
`Maven.fromMvnw()` uses the `distributionUrl` from `.mvn/wrapper/maven-wrapper.properties` as configured there.
